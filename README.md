# react-frontend

Exemplo de aplicação com o título Hello World e o alerta da soma de 4 + 3.

Requer Node.js 22.13 ou superior e pnpm 11.25.0.

- `pnpm install --frozen-lockfile`: instala as versões registradas.
- `pnpm dev`: inicia o servidor local.
- `pnpm build`: gera a aplicação em `dist/`.
- `pnpm preview`: serve o resultado da compilação.
- `pnpm audit`: verifica vulnerabilidades conhecidas nas dependências.

Vite substitui a configuração antiga de webpack e Babel. As dependências e a saída de compilação não são versionadas.
